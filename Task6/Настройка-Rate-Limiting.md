# Задание 6. Настройка Rate Limiting

1. Выделяем зону памяти для отслеживания лимитов.
```
    limit_req_zone $binary_remote_addr zone=api_limit_zone:10m rate=10r/m;
```

Считаем запросы по IP-адресу клиента:
```
$binary_remote_addr
```

Выделяем 10 мегабайт памяти под базу IP (хватит на ~160 000 адресов):
```
zone=api_limit_zone:10m
```

Устанавливаем лимит: не более 10 запросов в минуту:
```
rate=10r/m
```

2. Переопределяем стандартный HTTP-код на 429 при превышении лимита только для сервера на порту 80:

```
limit_req_status 429;
```

3. Применяем созданную зону к конкретному локейшену
```
limit_req zone=api_limit_zone burst=3 nodelay;
```
